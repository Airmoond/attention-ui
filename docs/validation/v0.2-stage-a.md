# 0.2 阶段 A：真实场景基线与 PDF 技术验证

日期：2026-09-23。分支：`codex/v0.2-real-world`，基线：`v0.1.0-beta`。

## 当前结论

已完成工程样本基线和独立 PDF 验证页，证明 PDF.js 本地阅读、中文文本选择、缩放和页码定位路线可行。正式插件尚未增加 PDF 或新网站功能。

阶段 A 的工程验证已完成；完整人工场景验收及真实学生资料覆盖仍待补充，不将 10 份原创工程 PDF 视为已覆盖实际教材。尚未进入阶段 B 或 C-PDF 的正式集成。

## 样本与证据

- [样本目录](v0.2-catalog.json)：中英文维基百科共 10 个条目、百度百科 10 个条目；记录目标段落、学生阅读任务和测试重点。
- [网站访问记录](v0.2-web-observations.json)：本机 Chrome 对 20 个固定地址逐一访问，均返回 HTTP 200、词条标题和主标题。仅证明当次可访问；没有加载 FocusUI 插件，不代表适配已通过。百度百科的最终义项地址按记录复验。
- PDF：生成 10 份原创文本型文档，每份 3 页，中文/英文各 5 份，其中 4 份双栏；另有扫描、加密、损坏、121 页超限样本。文件位于 `tools/pdf-spike/fixtures/`，生成器及其内容纳入 Git，二进制可重新生成。
- 样本针对字体、选区和页码边界，排版种类有限；后续必须加入学生有权提供的实际课程资料。
- 网页清单覆盖多学科内容；动态加载、网页输入、专注退出和页面内跳转的实际插件操作仍待后续适配验收。

## 手动复验

1. 在 `tools/pdf-spike` 运行 `npm ci`、`python generate-fixtures.py`、`npm run dev`。
2. 打开 http://127.0.0.1:4178，选择 `fixtures/sample-03.pdf`。
3. 跳到第 2 页，设置 150% 缩放，拖选正文或页码锚点；点击“记录此片段”。
4. 切到第 3 页，再点击“返回来源页”，确认回到第 2 页，片段与原文对应。
5. 关闭文档，确认片段消失；依次打开异常样本，核对提示。
6. 若测试真实学生资料，仅在本机打开；此实验没有上传或 AI 入口。
