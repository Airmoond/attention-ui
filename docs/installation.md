# AttentionUI 安装指南

适用于 AttentionUI 0.1.1 学生测试版。准备 Windows 10/11 64 位电脑、Google Chrome 和项目团队提供的测试包，按以下六步安装。

## 1. 解压测试包

1. 将 `AttentionUI-0.1.1-StudentTest-20261003.zip` 保存到电脑。
2. 右键点击 ZIP，选择“全部解压缩”。
3. 选择保存位置，点击“提取”，等待解压完成。
4. 打开解压后的 `0.1.1-attentionui-student-20261003` 文件夹，找到 `AttentionUI-Setup-0.1.1.exe`。

## 2. 安装并启动桌面程序

1. 如果已运行旧版本，右键点击任务栏右下角的程序托盘图标，选择“退出”。首次安装直接进入下一步。
2. 双击 `AttentionUI-Setup-0.1.1.exe`，打开安装向导。
3. 按向导选择安装目录，点击“安装”，等待结束后点击“完成”。
4. 双击桌面的 AttentionUI 快捷方式，或从开始菜单打开 AttentionUI。
5. 在左侧“运行状态”确认版本为 **0.1.1**、本地服务为 **运行中**。如尚未运行，点击“启动服务”。

保持桌面程序运行。默认服务地址为 `http://127.0.0.1:17321`。

## 3. 加载 Chrome 插件

1. 在 AttentionUI 左侧点击“快速上手”。
2. 点击“打开插件文件夹并复制路径”。程序会打开插件文件夹，并把路径复制到剪贴板。
3. 打开 Google Chrome，在地址栏输入 `chrome://extensions`，按回车。
4. 开启页面右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 在文件夹选择窗口中，点击上方地址栏，按 **Ctrl+V** 粘贴插件路径，再按回车。
7. 直接点击“选择文件夹”，完成加载。这个窗口选择的是文件夹，通常不显示其中的 JSON 文件。
8. 确认扩展列表出现 **AttentionUI 0.1.1 学生测试版**。
9. 点击 Chrome 工具栏上的扩展图标，将 AttentionUI 固定到工具栏。

已有旧插件时，停用或移除旧插件，再加载本次桌面程序提供的目录；如果加载目录相同，点击扩展卡片上的“重新加载”。

## 4. 连接桌面端与插件

1. 回到桌面程序的“运行状态”，复制配对令牌。
2. 点击 Chrome 工具栏中的 AttentionUI 图标，打开“连接与设置”。
3. 确认服务地址为 `http://127.0.0.1:17321`。
4. 粘贴配对令牌，点击“连接桌面端”。
5. 确认插件显示桌面端在线、已配对。

## 5. 填写并保存 AI 配置

1. 在桌面端左侧点击“AI 设置”。
2. 按服务商提供的信息填写 API 地址、API Key 和模型名称。例如使用 DeepSeek 时，API 地址可填写 `https://api.deepseek.com`，模型名称填写账号实际可用的模型标识。
3. 点击“测试连接”，等待成功提示。
4. 点击“保存设置”。

## 6. 启用网页并确认安装完成

1. 保持桌面程序运行，在 Chrome 打开 `http://127.0.0.1:17321/demo/article.html`。
2. 点击工具栏中的 AttentionUI 图标，打开插件弹窗。
3. 开启插件全局开关，点击“启用此网站”；出现 Chrome 授权提示时完成授权。
4. 刷新页面，在正文中拖选一段文字。
5. 按 **Alt+Shift+F**，或在插件弹窗点击“对选中文字使用工具”。
6. 确认选文旁出现工具条，点击“总结”或“解释”并等待结果。

完成后，可以继续打开财经示例 `http://127.0.0.1:17321/demo/finance.html`，体验数字内容的图表与数据工具。
