# FocusUI 0.1.1 学生测试版

构建日期：2026年10月3日。面向受邀同学的小范围网页测试，包含网站控制、手动选文及悬停不覆盖当前AI交互的修复。本版不代表0.2完整开发计划已经完成。

## 同学先看这里

详细步骤见包内 **安装使用说明书.html**（与 QUICK_START.html 内容相同）。双击即可离线打开，无需安装编程工具。

1. 完整解压测试包，运行 `FocusUI-Setup-0.1.1.exe` 安装桌面端。
2. 桌面端“快速上手”点击“打开插件文件夹并复制路径”。
3. Chrome 打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，加载复制路径中直接含 `manifest.json` 的文件夹。
4. 桌面端复制配对令牌，插件“连接与设置”粘贴令牌，点击“连接桌面端”。默认服务地址为 `http://127.0.0.1:17321`。
5. 桌面端“AI设置”填写自己服务商的API地址、API Key和模型名称，测试连接成功后点击“保存设置”。本包不提供账号或真实密钥。
6. 用Chrome打开桌面端提供的文章/财经Demo，在FocusUI弹窗先“启用此网站”。默认手动模式：选中文字，按 **Alt+Shift+F**，或点击弹窗“对选中文字使用工具”。
7. 按说明书的测试清单体验，填写 `测试反馈表.txt` 并发回项目负责人。

没有AI账号时仍可测试安装、网站控制、工具条和专注阅读；AI部分标记未测试即可。关闭主窗口会留在系统托盘，右键托盘“退出”才完全停止程序。

## 系统与支持范围

- Windows 10/11 x64 + Google Chrome；扩展采用开发者模式加载，安装包未商业代码签名。
- 本机Demo、中文/英文维基百科、百度百科正文。复杂百科布局仍需试用反馈；未开放任意网站。
- 总结、解释、片段提问、专注阅读、图表和数据提取。工具随内容变化，最多三个候选；文章右侧“提问练习”提供提问测试位置。
- 网站启停、当前标签页暂停、手动选文、可选自动工具条。**自动工具条与自动AI推荐独立，默认都关闭。**
- 本轮安装包不含独立PDF阅读页和公式识别实验；它们尚未正式集成。

## 升级旧版

从托盘退出旧版，再安装本版。优先保持原安装目录。插件加载目录没变时到扩展管理页重新加载，确认版本0.1.1并刷新网页；若来自另一独立目录，先停用/移除旧插件再加载本次内置版本。重新加载不等于网页刷新，两步都要完成。安装后检查AI配置；必要时重配插件并重新启用网站。不要同时启用两个FocusUI。

## Demo地址

保持桌面端服务运行，在Chrome打开：

- `http://127.0.0.1:17321/demo/article.html`
- `http://127.0.0.1:17321/demo/finance.html`

页面随桌面安装，不依赖外部CDN；AI需要连接所配置的服务商。独立备份页面直接以file路径打开不支持插件测试。

## 内容发送说明

新网站默认关闭。手动默认只在点击AI工具时发送必要片段；开启自动AI推荐会额外发送片段并可能计费。发送内容不包括整页HTML、网页标题、URL查询参数和完整浏览历史。排除输入、密码框和可编辑区域，日志不存完整正文、问题和答案。API Key仅在桌面端保存；本轮未完成操作系统级密钥存储加固。AI输出需要对照原文核对。

## 开发者构建

```powershell
npm install
npm run typecheck
npm test
npm run package:release
npm run verify:release
node scripts/test-site-controls.mjs
```

发布脚本默认构建日期20261003，可通过PowerShell参数`-BuildDate YYYYMMDD`指定另一批次。输出目录 `release/0.1.1-student-20261003/`；保持历史Beta归档。日期总包、校验值与验证范围见 `docs/releases/v0.1.1-student-test.md`。浏览器回归复用 `tools/pdf-spike` 中已有的独立测试环境，不依赖真实AI。

同学只需接收最终ZIP，无需接收源码、测试浏览器、模型文件或个人讲义。
