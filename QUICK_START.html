1 · 这版能测试什么

FocusUI 由 Windows 桌面程序和 Chrome 插件组成。插件在你正在阅读的内容附近显示工具，桌面程序连接你配置的 AI 服务。

可以测试本版边界
选中文字后总结、解释；在提供“提问”按钮的内容上提问每次围绕当前片段回答，不是整篇文章或整本教材问答
文章专注阅读、数字/表格生成图表和提取数据工具随内容变化，一次通常最多显示三个；并非每段都有全部按钮
网站启用/禁用、标签页暂停、可选自动工具条初次使用要启用网站；默认手动，鼠标移动不会自动调用 AI
本机文章/财经 Demo；中英文维基百科与百度百科正文试用百科复杂排版尚在收集反馈；其他网站未开放

PDF 说明：此前的 PDF 阅读与公式识别是独立实验，本次安装包没有“打开本地 PDF”入口。请用网页和内置 Demo 测试，不需要寻找 PDF 功能；公式识别也不是本版验收任务。

本版包含“解释生成中鼠标移到另一段，窗口仍保持当前任务”的修复。AI 回答仍需结合原文核对。

2 · 安装前准备与文件清单

  • 电脑：Windows 10/11，64 位；浏览器：Google Chrome。手机、Mac、Firefox、Edge 不在本轮验证范围。
  • 使用 AI 需要可访问所选服务商的网络、可用 API Key 和模型名称；本包不附带账号或共享密钥。
  • 没有 API 的同学仍可测试安装、网站控制、选文工具条和专注阅读，AI 任务标记为“未测试”即可。
  1. 收到 FocusUI-0.1.1-StudentTest-20261003.zip 后，右键选择“全部解压缩”。
  2. 打开解压后的文件夹，先打开 安装使用说明书.html。不要直接从压缩包内部运行安装程序。
  3. 解压路径任选，例如“下载/FocusUI测试包”；后续插件采用桌面端内置目录，避免加载临时解压路径。

3 · 安装桌面程序

  1. 如装过旧版，先按第10节从系统托盘退出旧 FocusUI。
  2. 双击 FocusUI-Setup-0.1.1.exe，按向导选择安装目录并完成安装。建议保留默认目录。
  3. 从桌面或开始菜单打开 FocusUI。左侧应有“快速上手”“运行状态”“AI设置”“交互设置”“调试日志”。
  4. 打开“运行状态”，确认“本地服务”为“运行中”，服务地址为 http://127.0.0.1:17321，应用版本为 0.1.1。
  5. 若服务未启动，点击“启动服务”；若显示端口占用，先看第12节，不要不断重复安装。

测试安装包尚未商业代码签名。遇到 Windows 来源提示时，先确认文件来自项目负责人、名称与本文一致；组织管理策略阻止运行时联系负责人。无需关闭杀毒软件或修改系统安全设置。

主窗口右上角“×”会隐藏到系统托盘，桌面服务仍在后台运行。完全退出方式见第9节。

4 · 安装 Chrome 插件

推荐使用安装包内置插件：

  1. 在 FocusUI 桌面程序左侧点击“快速上手”。
  2. 点击“打开插件文件夹并复制路径”。会打开文件夹，并自动复制其路径。
  3. 打开 Chrome，在地址栏手动输入 chrome://extensions 并回车。
  4. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”。
  5. 在文件夹选择窗口的地址栏粘贴刚才复制的路径，进入该文件夹，再点击“选择文件夹”。选的是直接包含 manifest.json 的文件夹。
  6. 扩展管理页应出现“FocusUI 0.1.1 学生测试版”卡片。确认开关开启。
  7. 点击 Chrome 工具栏的拼图图标，找到 FocusUI，点击图钉固定到工具栏。

此步骤需要你手动确认，因为本版插件尚未上架商店。不要把 ZIP 文件直接拖进 Chrome，也不要选桌面安装目录的最外层。

备用方式：加载独立插件 ZIP

只有内置目录无法访问时，解压 focusui-extension.zip 到一个长期保留的目录，再加载其中直接包含 manifest.json 的文件夹。之后不要移动或删除它。两个方式任选一个，避免同时启用重复插件。

5 · 连接桌面端与插件

  1. 保持 FocusUI 桌面程序运行，在“快速上手”或“运行状态”点击“复制配对令牌”。
  2. 点击 Chrome 工具栏的 FocusUI 图标，再点击“连接与设置”。
  3. “桌面服务地址”保持 http://127.0.0.1:17321，如果改动过，点击“保存服务地址”。
  4. 将刚复制的值粘贴到“配对令牌”，点击“连接桌面端”。这里粘贴配对令牌，不是 API Key。
  5. 关闭设置页，重新打开工具栏弹窗，应显示“桌面端：在线 · 已配对”。

令牌仅用于连接本机。每位同学在自己的桌面端复制自己的令牌，不复制其他人的配置；正常情况下不必每次重新配对。桌面端重新生成令牌或断开插件后，需要再配对。

6 · 配置 AI

  1. 在桌面端打开“AI设置”。
  2. 填写下表三项。API 地址与模型名称由服务商或测试负责人提供；API Key 在服务商的 API 控制台申请。
  3. 点击“测试连接”。这会发起一次真实模型请求，成功后应出现“AI服务连接成功”。
  4. 再点击“保存设置”，确认显示“设置已保存。”。测试成功本身不会保存配置。
界面字段怎么填写
API地址OpenAI 兼容的对话接口基础地址。若使用 DeepSeek 官方服务，可填 https://api.deepseek.com；其他服务商按其文档填写。不要填聊天网页地址。
API Key粘贴自己账户的 API 密钥；不要加引号、空格或“Bearer”。聊天应用账号/会员不等于 API 密钥。
模型名称填服务商后台当前可用的模型标识，逐字复制。不要只写“DeepSeek”这样的品牌名；本轮没有验证所有模型。

AI 需要联网，API 调用可能按服务商规则计费。建议先完成少量测试，不开启“自动 AI 工具推荐”；账户余额、额度和权限不足会导致失败。优先使用能及时返回的普通对话模型，较慢的推理模型可能触发本版超时。

地址说明依据 DeepSeek 官方首次调用文档 核对，核对日期为2026年10月3日。是否可调用仍以自己的账户及“测试连接”结果为准。本包没有代填或分发真实密钥。

7 · 5分钟快速上手：第一次使用

打开网页→启用网站→选中文字→Alt + Shift + F→点击工具
  1. 在桌面端“快速上手”点击“打开文章Demo”。如果默认打开的不是 Chrome，把下方地址复制到 Chrome 打开。
  2. 在这个 Demo 标签页里点击 Chrome 工具栏的 FocusUI 图标，勾选“全局启用 FocusUI”，点击“启用此网站”。若 Chrome 弹出网站访问申请，确认允许后继续。
  3. 保留两个自动开关关闭，回到网页，在正文拖选一小段文字。避开搜索框、按钮、导航、广告。
  4. 按 Alt + Shift + F。也可在保留选文后打开 FocusUI 弹窗，点击“对选中文字使用工具”。
  5. 工具条出现后点击“解释”或“总结”。等结果出现，用“关闭”或 Esc 退出。
  6. 若刚安装或重新加载插件，刷新网页后重试。每个网站第一次都需要启用；中英文维基百科分别设置。

打开文章 Demo · 打开财经 Demo（均需桌面端服务运行；页面内容可离线阅读，AI 仍需网络）。

验收标志：工具条出现在选文附近，解释结果对应选中的内容；等待时把鼠标移到其他段落，窗口和原任务仍保留。

尝试百科正文

在 Chrome 打开 https://zh.wikipedia.org、https://en.wikipedia.org 或 https://baike.baidu.com 中的实际词条页。先启用该网站，再用相同的选文步骤操作。首页、搜索框、编辑页和动态浮层不是优先测试位置。网页打不开时先检查网页本身能否访问；可返回内置 Demo 继续测试。

8 · 各种工具怎么用

工具操作与预期
总结选取正文片段，点击“总结”。检查是否保留主要信息、有没有混入相邻无关段落。
解释选取难懂概念，点击“解释”。生成时移到另一段、生成后再移动，窗口应保留当前结果。
提问在提供此按钮的内容上点击“提问”，输入问题并点“发送”，也可 Ctrl + Enter。最多500字；空问题不能发送。可在文章 Demo 右侧“提问练习”中测试。移动鼠标时草稿应保留。
专注在文章正文工具条点“专注”，进入独立阅读面板。点关闭或 Esc 退出，原网页应恢复，可继续滚动。无需 AI。
生成图表在财经 Demo 选择明确的年度营收段落或表格。点“生成图表”，核对标签、数值、单位；是否为柱状或折线取决于返回结果，不能保证每次各生成一种。
提取数据在数据内容中点“提取数据”，核对字段与原文。无法建立可靠对应关系时，提示失败是允许的，不应编造数据。

工具条最多显示三个候选，长文可能是“专注/总结/解释”，短文、代码和数字内容组合不同。未出现“提问”时，换到上述练习段落；不要认为任何片段都必须显示全部功能。

结果窗口“返回”回到当前片段的工具条；“关闭”、Esc 或点击窗口外部可结束当前窗口。重新选文并主动使用快捷键，会切换到新片段。一次片段长度有上限（约1500字符），建议选择一两段，不要一次选整页。

9 · 自动模式、暂停与退出

控制项作用
全局启用 FocusUI关闭后所有标签页停止使用；重新开启后还要看当前网站是否启用。
启用/禁用此网站同一网站的设置会保存。禁用后不再在该网站显示工具。
鼠标停留时自动显示工具条开启后在稳定停留的正文附近显示工具条。默认等待约一秒，滚动或快速划过不会触发。
自动 AI 工具推荐额外把当前片段发送给 AI 来推荐工具；与自动工具条独立。手动唤起工具条时也可能请求推荐，默认关闭以减少发送与费用。
暂停/恢复此标签页只影响当前标签页，其他标签页仍可使用；关闭该标签页后临时暂停结束。

自动模式下，同一元素有约30秒冷却，关闭后立刻回到同一段可能不再弹出；可以换一段或使用手动快捷键。加载中、结果显示中和输入问题时，移到别段不会抢走当前窗口。暂停/禁用后，旧回答不能重新弹出；已开始的 AI 请求不能保证因此停止处理或取消计费。

后台运行与完全退出

关闭主窗口后 FocusUI 留在系统托盘。点击任务栏右下角“隐藏的图标”箭头，找到 FocusUI，右键选择“退出”，才会完全退出并释放本机服务端口。下次使用前重新打开桌面程序。

10 · 旧版升级与卸载

  1. 先从系统托盘退出旧 FocusUI，再运行本次安装程序；已有安装建议选择原来的安装目录。
  2. 打开新桌面端，确认版本0.1.1；检查 AI 配置是否保留。若为空，用自己的配置重新填写、测试并保存。
  3. 在 chrome://extensions 查找旧 FocusUI。加载目录仍是同一安装位置时，点击旧卡片的“重新加载”图标，确认显示0.1.1。
  4. 若旧插件来自另一个独立文件夹，先关闭或移除旧插件，再按第4节加载本次内置插件。不要留下两个同时启用的版本；移除旧扩展可能清除它的本地设置。
  5. 刷新所有待测网页。出现“需要配对”时按第5节重配；第一次使用当前网站时重新启用，自动开关默认保持关闭。

卸载：先从托盘退出桌面程序，在 Windows“设置→应用”中卸载 FocusUI；插件另到 Chrome 扩展管理页点击“移除”。卸载桌面端不等于卸载 Chrome 插件，也不承诺清除所有用户配置；需要彻底清理时联系项目负责人，不要随意删除其他应用目录。

11 · 建议测试任务与反馈

第一轮约15—20分钟即可。先完成安装和 Demo，再体验一个自己正在学习的百科词条。AI 无法配置时如实记录，仍可完成本地测试。

  • 桌面端能启动；插件能加载并显示0.1.1；配对成功。
  • 默认两个自动开关关闭时，单纯移动鼠标不弹工具条；选文快捷键可以唤起。
  • 文章 Demo 的总结和解释能对应所选内容；专注进出后原网页滚动正常。
  • 解释正在生成时移到其他段落，等待窗口不消失；结果出现后移动鼠标，结果仍保留。
  • 在“提问练习”输入问题，移到别段后草稿仍在；发送后答案对应当前内容。
  • 财经 Demo 年度营收原文为2023年80亿元、2024年105亿元、2025年136亿元，图表应与原文一致。
  • 开启自动工具条后能在正文稳定停留时出现；自动 AI 推荐关闭时无需为每次悬停请求 AI。
  • 暂停当前标签页后窗口清理；另一个已启用标签页仍可用；恢复后可继续操作。
  • 禁用网站后刷新，工具条仍不出现；重新启用可恢复。
  • 选择一个百科词条，记录在哪段、什么操作不顺畅；搜索框/输入框中不应触发读取工具。

12 · 常见问题排查

现象按顺序检查
桌面安装程序打不开确认已完整解压、使用Windows 64位、文件来自本轮测试包。组织策略拦截时联系负责人，不关闭安全软件。
插件提示清单/manifest不存在重新点击桌面端“打开插件文件夹并复制路径”，选择直接包含manifest.json的文件夹，不选择ZIP或父目录。
桌面端离线打开桌面端检查“本地服务：运行中”，必要时点击“启动服务”。确认插件地址没有改动；关闭并重开插件弹窗更新状态。
端口17321被占用退出系统托盘里仍在运行的旧 FocusUI，重新打开本版。若仍占用，提供错误截图；不要结束不认识的进程或修改端口。
需要配对/令牌失效从本机桌面端复制当前令牌，插件“连接与设置”中重配。不要将API Key粘贴到配对栏。
网页上没有工具条确认支持的网站、插件已启用、全局开关开启、网站已启用且未暂停；刷新网页。默认用选文快捷键，自动模式需另开。避开输入、导航、隐藏区域；不要跨过可编辑区域选文。
快捷键无响应先选中文字并让焦点在网页，使用左侧Alt + Shift + F。系统或其他软件占用快捷键时，用弹窗“对选中文字使用工具”。
当前页面暂不支持本版仅中英文维基百科、百度百科和本机Demo。Chrome设置页、商店、新标签页、其他网站、本地PDF不支持。
AI连接失败/没有回答先在桌面端“AI设置”测试连接并保存。核对API地址、模型、密钥、网络、余额和权限。较慢响应可能超时，记录提示后主动重试，避免连续点击。
工具按钮与截图/其他人不同这是按内容类型选择最多三个工具及轻量习惯排序的结果。到指定Demo段落重试；长文不一定提供提问。
网页打开在其他浏览器把Demo地址复制到Chrome。桌面端使用系统默认浏览器打开，插件测试仍需Chrome。
找不到PDF入口本轮没有打包独立PDF阅读/公式实验，此项无需测试。

13 · 内容发送与使用边界

  • 新网站默认关闭；启用后允许处理本站选文或关注段落。手动默认仅点击AI工具才发送必要片段；开启自动AI推荐后会额外发送片段。
  • 发送给你配置的AI服务的内容包含必要片段和去掉查询参数/片段的网址路径，不发送整页HTML、网页标题或完整浏览历史。若原文含个人信息，请先缩小选区或避免调用AI。
  • API Key只保存在桌面端，不进入插件或分发包；当前版本尚未完成操作系统级密钥存储加固，测试后妥善管理本机配置。
  • 程序排除输入、密码框、可编辑区域等；日志不保存完整正文、完整问题和完整回答。习惯数据主要是工具与内容类型的使用次数。
  • AI答案和图表需要与原文核对，本轮用于学习辅助测试。长文、公式、复杂表格及动态百科排版可能有误差，请记录样例。
