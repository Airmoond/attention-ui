FOCUSUI 0.1.0 BETA

5分钟快速上手

这份说明面向第一次接触浏览器插件的用户。无需命令行，按顺序完成四步即可开始体验。

1

安装 Chrome 插件

  1. 打开 FocusUI Desktop，进入左侧“快速上手”。
  2. 点击“打开插件文件夹并复制路径”。FocusUI 会打开内置生产插件的位置，并把路径复制好。
  3. 在 Chrome 地址栏输入 chrome://extensions 并回车。
  4. 打开页面右上角“开发者模式”。
  5. 点击左上角“加载已解压的扩展程序”。在文件夹选择窗口粘贴刚才复制的路径，选择该文件夹。
  6. 看到 FocusUI 卡片后即安装成功。建议点击 Chrome 工具栏的拼图图标，把 FocusUI 固定到工具栏。

Chrome 出于安全考虑，不允许普通安装程序静默安装未上架扩展，因此“加载已解压的扩展程序”这一步必须由用户确认。

2

连接 Desktop

  1. 在 Desktop“快速上手”点击“复制配对令牌”。
  2. 打开 Chrome 工具栏中的 FocusUI，确认显示“桌面端：在线”。
  3. 打开插件“选项”，粘贴配对令牌并点击连接。
  4. Popup 显示“配对：已配对”即完成。

配对只连接本机的 127.0.0.1:17321 服务。不要把配对令牌发送给其他人。

3

配置 AI

进入 Desktop“AI设置”，填写服务商提供的三项内容：

项目示例或说明
Base URLOpenAI 兼容接口地址，请以服务商文档为准。
API Key服务商提供的密钥，仅保存在 Desktop。
模型名称例如服务商支持的对话模型标识。

先点击“测试连接”，成功后保存。API Key 不会进入 Chrome 插件或演示网页。

4

体验两个 Demo

保持 Desktop 在运行，在 Chrome 中打开：

文章 Demo：总结、解释、提问、专注阅读 财经 Demo：生成图表、解释、提取数据

正确操作方式

  1. 把鼠标稳定停在一段正文或一组明确数字上，等待工具条出现。
  2. 文章页尝试“总结”“解释”“提问”“专注”。财经页尝试“生成图表”和“提取数据”。
  3. 若刚加载插件，请刷新已打开的 Demo 标签页一次。

常见问题

插件显示 Desktop 未连接

确认 FocusUI 正在运行。关闭主窗口不会退出，它会留在系统托盘；可点击 Popup 的“重新检测”。

网页上没有出现工具条

在 chrome://extensions 确认 FocusUI 已启用，然后刷新 Demo 页面，把鼠标停在正文而不是按钮、输入框或广告区域。

提示需要重新配对

重新从 Desktop 复制当前配对令牌，到插件“选项”页面连接。

AI 服务连接失败

核对 Base URL、API Key 和模型名称。可先在 Desktop“AI设置”中测试连接。

如何彻底退出

右键系统托盘中的 FocusUI 图标，选择“退出”。只关闭窗口时服务仍会在后台运行。

隐私说明

  • 网页只发送当前关注的内容块，不发送完整浏览历史。
  • API Key 只保存在 Desktop，不进入 Extension。
  • 日志不保存完整网页正文、完整问题或完整 AI 回答。
  • 用户习惯只统计工具 ID、内容类型与次数。
