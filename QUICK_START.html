FocusUI 0.1.1 学生测试版

安装说明书

在 Windows 10/11 64 位电脑上使用 Google Chrome，依次完成以下六步。

安装步骤

  1. 解压测试包
  2. 安装并启动桌面程序
  3. 加载 Chrome 插件
  4. 连接桌面端与插件
  5. 填写并保存 AI 配置
  6. 启用网页并确认安装完成

1 · 解压测试包

  1. 将收到的 FocusUI-0.1.1-StudentTest-20261003.zip 保存到电脑，例如“下载”文件夹。
  2. 右键点击 ZIP，选择“全部解压缩”。
  3. 选择保存位置，点击“提取”，等待解压完成。
  4. 打开解压后的 0.1.1-student-20261003 文件夹，找到 FocusUI-Setup-0.1.1.exe。

2 · 安装并启动桌面程序

  1. 如果电脑上已有 FocusUI，点击任务栏右下角的“隐藏的图标”箭头，右键点击 FocusUI 图标，选择“退出”。首次安装直接进行下一步。
  2. 双击解压文件夹中的 FocusUI-Setup-0.1.1.exe，打开安装向导。
  3. 按向导选择安装目录。可以保留默认目录，也可以点击“浏览”选择位置。
  4. 点击“安装”，等待安装结束，再点击“完成”。
  5. 双击桌面的 FocusUI 快捷方式，或在开始菜单中搜索并打开 FocusUI。
  6. 点击左侧“运行状态”。确认应用版本为 0.1.1，本地服务显示“运行中”；如果显示未运行，点击“启动服务”。

桌面服务地址：http://127.0.0.1:17321。接下来保持 FocusUI 运行，继续安装插件。

3 · 加载 Chrome 插件

  1. 在 FocusUI 左侧点击“快速上手”。
  2. 点击“打开插件文件夹并复制路径”。程序会打开插件文件夹，同时将路径复制到剪贴板。
  3. 打开 Google Chrome，在地址栏输入 chrome://extensions，按回车。
  4. 开启页面右上角的“开发者模式”开关。
  5. 点击页面左上角的“加载已解压的扩展程序”。
  6. 在文件夹选择窗口中，点击上方地址栏，按 Ctrl + V 粘贴刚复制的插件路径，再按回车。
  7. 确认地址栏是刚才粘贴的插件路径，直接点击“选择文件夹”，完成加载。这个窗口用于选择文件夹，JSON 文件不会显示在列表中。
  8. 扩展管理页会出现“FocusUI 0.1.1 学生测试版”卡片，打开卡片上的启用开关。已有同一安装目录的插件时，点击其“重新加载”按钮更新；来自其他目录的旧插件先关闭，再加载本次插件。
  9. 点击 Chrome 工具栏右侧的拼图图标，在列表中找到 FocusUI，点击旁边的图钉，将它固定到工具栏。

Chrome 工具栏中出现 FocusUI 图标后，继续完成配对。

4 · 连接桌面端与插件

  1. 回到 FocusUI 桌面程序的“快速上手”页面，点击“复制配对令牌”。
  2. 在 Chrome 中点击工具栏的 FocusUI 图标，点击“连接与设置”。
  3. 在“桌面服务地址”中填写 http://127.0.0.1:17321，点击“保存服务地址”。已有此地址时直接进行下一步。
  4. 点击“配对令牌”输入框，按 Ctrl + V 粘贴从桌面程序复制的令牌。
  5. 点击“连接桌面端”，等待页面显示“当前配对状态：已配对”。
  6. 关闭设置页，重新点击 Chrome 工具栏的 FocusUI 图标。

弹窗显示“桌面端：在线 · 已配对”，表示连接完成。

5 · 填写并保存 AI 配置

  1. 回到 FocusUI 桌面程序，点击左侧“AI设置”。
  2. 填写“API地址”“API Key”和“模型名称”三个字段，填写方式见下表。
  3. 点击“测试连接”，等待出现“AI服务连接成功”。
  4. 点击“保存设置”，等待出现“设置已保存。”。
字段填写内容
API地址填写服务商提供的 API 基础地址。DeepSeek 官方服务填写 https://api.deepseek.com。
API Key填写服务商 API 控制台生成的密钥，直接粘贴密钥本身。
模型名称填写服务商控制台或文档中的模型标识，完整复制该名称。

完成“测试连接”和“保存设置”两步后，AI 配置完成。

6 · 启用网页并确认安装完成

  1. 在 FocusUI 的“快速上手”页面点击“打开文章Demo”。也可以在 Chrome 输入 http://127.0.0.1:17321/demo/article.html，或点击打开文章 Demo。
  2. 在文章 Demo 标签页中，点击 Chrome 工具栏的 FocusUI 图标。
  3. 打开“全局启用 FocusUI”开关，点击“启用此网站”。Chrome 出现网站访问申请时，点击允许。
  4. 关闭插件弹窗，刷新网页。
  5. 在正文中拖选一小段文字，按 Alt + Shift + F。

选中文字附近出现 FocusUI 工具条，安装完成。
